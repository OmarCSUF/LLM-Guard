# results/

This folder holds the stored outputs of the completed experiments. They are the source of truth for every number in the paper and in README.md; nothing here is regenerated by the release except the derived `analysis/` files, which `scripts/final_eval/analyse_final.py` and the six post hoc scripts recompute byte-identically from the per-prompt prediction files (checked by `tests/test_analysis_regeneration.py`).

| Folder | Contents |
|---|---|
| `final_eval_20260926/` | The pre-registered final evaluation (26 Sep 2026) and its post hoc additions: `PREREGISTRATION.md`, the five dated `AMENDMENT-*.md`, `frozen.json` (freeze record), `checkpoints.json`, `final_manifest.json` and `final_test.jsonl` (the 3,453-prompt test set), one `<arm>.json` + `<arm>_predictions/` per arm (27 on the final set, 4 on the pool validation split, 1 Layer-1 pass over the pool test split), the three repeat-study red-team passes and the historical pass, the learner arms per seed, `sentence_essay_writer_mapping.jsonl`, `analysis/` (every table of the paper), `logs/`, `withdrawn_badstep_20260928/` (a withdrawn Llama Guard run, kept for the record) and `superseded/`. |
| `development/` | Development-stage results the README, the pre-registration or the analysis scripts refer to: the views-off/on HarmBench attack passes of 22 Sep (inputs of `paired_views.py`), the judge tuning runs (inputs of `calibration.py`), the routing-band sweep (Table XIII), the historical learner runs, the development-benchmark ablation and parity studies, the leak-review inputs, and the build manifests of every dataset (`pool_metadata.json`, `raw_sources_manifest.json`, `raw_final_sources_manifest.json`, `learner_arms_manifest.json`, `parity_arms_manifest.json`). |
| `repeat_study_nciJu1oQ/` | Protocol and freeze record of the three-seed retraining study (seeds 42/43/44) whose checkpoints ship in `artifacts/`, plus the training entry point as it was at the time (`training_entrypoint.py`, preserved verbatim; the current `scripts/repeat_study_nciJu1oQ_train.py` is a shim onto `scripts/train_layer1.py --seed`). |

## Provenance records

Every result JSON carries a `run_info` block (`src/llmguard/utils/run_info.py`): the exact command, working directory, seed, git commit and dirty flag, Python and package versions, GPU, and a snapshot of the configuration. These blocks are kept exactly as written; they therefore record the original machine's paths (`/home/OmarLaptop/venvs/guard/bin/python`, `/home/OmarLaptop/Omar/GaurdLLm-vibe-main`, the local Qwen directory that the release config replaces with the hub id at the verified revision). Times in `run_info` are UTC; the `logs/` files are stamped in local time (UTC+8).

## Prompt texts removed

The learner prediction files (W&I+LOCNESS sentences, non-redistributable) and the pool validation/test prediction files (prompts from gated and non-commercial sources) had their `text` field removed with `scripts/tools/strip_text.py`; ids, labels, decisions and scores are unchanged, and `final_eval_20260926/TEXT_REMOVED.md` lists each file with its SHA-256 before and after. The analysis scripts read only ids, labels, decisions and scores, and regenerate the stored tables unchanged.
